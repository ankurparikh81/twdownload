# Privacy Policy for twdownload

Last updated: October 2026

## 1. Overview
`twdownload` is a browser extension and open-source command-line tool designed to help users download public media (videos, photos, and GIFs) from posts on X (formerly Twitter). We value user privacy and believe in minimal, transparent data handling.

## 2. Information We Collect
**`twdownload` does not collect, store, transmit, or sell any personal data.**
- No user accounts or personal profiles are created or tracked.
- No analytics, tracking beacons, cookies, or telemetry are collected or transmitted to any third-party server.
- No browsing history or activity outside of the current active tab's URL (when the toolbar icon is clicked) is accessed.

## 3. How Permissions Are Used
- **`activeTab`**: Used strictly when you click the extension's toolbar icon to read the URL of the current tab on X/Twitter to identify the tweet.
- **`downloads`**: Used strictly to initiate the download of your chosen video or photo file and save it to your local Downloads folder.
- **`scripting`**: Used strictly to detect if an active tweet modal or video is open on X/Twitter timeline pages.
- **Host Permissions (`api.fxtwitter.com`, `cdn.syndication.twimg.com`, `video.twimg.com`, `pbs.twimg.com`)**: Used strictly to query public tweet media metadata and download the selected media stream from public CDN endpoints.

## 4. Third-Party Services
When fetching media details, requests are routed to public metadata endpoints (such as `api.fxtwitter.com` and Twitter's public syndication CDN) to retrieve media resolution variants. These requests only transmit the public Tweet status ID.

## 5. Changes to This Policy
Any updates to this privacy policy will be posted directly to this page.
